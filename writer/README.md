# 文笔坐标 —— 中文创意写作盲评（3:26）

10 个模型 × 107 题中文创意写作盲评，6 位裁判打分，去极值后的雷达图视频。在线看：https://bili.bemly.moe/writer/

- 浏览器实时渲染（35 张竖版卡片 DOM + Web Animations，音频时钟驱动），无需构建。
- `index.html`：播放页（顶栏 + 竖版舞台 + 播放/进度/时间/全屏；点击播放，空格暂停，←/→ 5 秒，R 重播，F 全屏，底部进度条可点）；`?t=秒` 冻结单帧（给出片 / 抽 still 用）。
- `cards/`：35 张卡片源文件（`00_总榜` → 10 个模型 → `90_模块榜` + 10 个模块 → `91_维度榜` + 11 个维度 → `92_裁判`，与成片顺序一致，直接复用汇总 HTML，自带 base64 图标，播放页按需抓取 `.card` 注入）。
- `timeline.json`：35 卡顺序 + 标题 + 淡入淡出 `0.4s`（每卡 `d=(T+0.4×34)/35≈6.27s`，卡间 `0.4s` 交叉淡化，由播放页按音频实时计算）。
- `audio/mix.m4a`：配乐（205.8s，播放页做主时钟，与成片一致）。
- `cover.jpg`：首页卡片用（1920×1080，由 `00_总榜.png` 高斯模糊垫底生成）。
- `tools/render.mjs`：Playwright 逐帧抓 `?t=` 进 ffmpeg（配 `audio/mix.m4a` 出成片，仓库根备 `python3 -m http.server 8765`）。

成片 mp4（25MB）、`_data.json` / 明细 CSV 等中间产物均未入库（见原汇总目录）。
