# AFM 拼音介绍视频 · 台词（Tingting 配音）


## 开场

- `0:01.2` 这是 AFM 拼音，一款 macOS 上的液态玻璃风格中文输入法。
- `0:07.4` 它用苹果端侧大模型增强候选预测，隐私安全，离线可用。

## 01 缘起

- `0:15.3` 故事要从 macOS 27 自带的 fm 命令说起，它是 Apple Foundation Models 的命令行入口。
- `0:23.7` 它是系统内置的通用二进制，开箱即用。
- `0:28.1` 可以直接对话，写代码、讲步骤都不在话下。
- `0:33.0` 推理跑在本机的神经引擎上，全程不用联网。
- `0:38.1` 模型还自带安全护栏，越界的提示词会被直接拦下。
- `0:43.7` 既然系统里就有大模型，为什么不让它帮我们打字呢？于是就有了这个输入法。

## 02 功能

- `0:52.2` 打字稍一停顿，模型就会结合上文，给最合适的候选打上星标，提到前排。
- `1:00.7` 日常打字和你熟悉的拼音一样：数字选词，空格上屏，简拼和模糊音都支持。
- `1:09.2` 词典引擎内置近七百万条词库，单次查询只要零点几毫秒。
- `1:16.0` 选中的候选是一颗透明的液态玻璃水滴，按住可以左右拖动，松手就上屏。
- `1:24.1` 设置里还能开启固定透镜模式：水滴钉在原地，候选条从它下面滑过。
- `1:32.0` 按下方向键，候选条会展开成可以滚动的网格。
- `1:37.6` 长句子词典覆盖不住时，模型会给出整句预测。当然，它偶尔也会把提示词原样念出来。
- `1:47.1` 这不是你的问题，也不是我的问题，是林檎的 LLM 又犯傻了。
- `1:53.5` Control+V 呼出剪贴板历史，Control+F 内联翻译，都不会打断组词。
- `2:02.0` 上过屏的词会被记住，越打越顺。
- `2:05.9` 觉得端侧不够用，可以在模型页填上接口地址和密钥，接入云端模型。
- `2:13.5` OpenAI 兼容和 Anthropic 两种格式都支持，失败了还会自动回落到端侧。
- `2:20.9` 模糊拼音、候选字号、快捷键，都能在设置中心里调整。

## 03 安装

- `2:28.5` 接下来是安装。最省事的办法，是用 Homebrew 装预编译版，它只支持 Apple 芯片。
- `2:36.6` 添加并信任 bemly/tahoe 这个源，再用 brew 安装 afm，输入法会自动装好并启用。
- `2:45.0` 想自己编译的话，需要 macOS 27 和 Xcode 27。
- `2:50.9` 克隆仓库，下载 Metal 工具链，再依次运行词库编译和打包两个脚本。
- `2:58.4` 打开生成的应用，在设置中心点击「安装并启用」。
- `3:03.9` 首次安装需要注销并重新登录一次。然后在系统设置的键盘输入法里，添加简体中文下的 AFM 拼音。
- `3:14.4` 看到「已安装并启用」，按 Control+空格，就可以切换过来打字了。

## 04 开启 Apple 智能

- `3:21.8` 最后，国行 Mac 默认没有 Apple 智能，可以用开源项目 enableMacosAI 来开启。
- `3:29.8` 它是一个内核扩展，把设备区域从国行改成美版，只支持 Apple 芯片和 macOS 27。
- `3:38.6` 第一步，进入恢复模式，运行屏幕上的命令，只关闭内核扩展的签名检查。
- `3:46.5` 第二步，克隆项目，用管理员权限运行安装脚本。
- `3:52.2` 第三步，到系统设置的隐私与安全性里点击允许，然后重启。
- `3:58.9` 另外，Apple 账户的媒体与购买项目要改到支持的地区，系统语言和 Siri 语言都设为美国英语。
- `4:08.3` 最后运行 status 体检，资格值显示为 4，端侧模型就可以用了。
- `4:15.4` 注意，这会降低一部分系统保护，请自行评估风险。

## 结尾

- `4:22.0` AFM 拼音完全开源，纯 Swift 编写，没有第三方依赖。欢迎到 GitHub 点一颗星。
