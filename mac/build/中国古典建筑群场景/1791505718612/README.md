# 3D 体素风格中国古典建筑群场景

这是一个使用 **Three.js** 构建的 3D 体素（voxel）风格中国古典建筑群场景，包含至少5座建筑，整体呈中轴对称布局。

---

## 🏯 场景介绍

**名称：** 古代宫城体素场景  
**风格：** 中国古典建筑 + 3D 体素化  
**技术栈：** Three.js (原生 JS)

### 建筑布局（中轴对称）

```
                    [ 宝塔 ]         [ 钟楼 ]
                       ↑                ↑
                  ┌──────┐        ┌──────┐
              [ 左配殿 ]           [ 右配殿 ]
                  ↑                ↑
    ┌──────────────┼───────┐   ┌─────┘        └──────┐
    │              ↑       │   │                    │
 [ 山门 ]      [ 主殿 ] [配殿]              ↓       ↓
    │              ↑       │                道路连接
    └──────────────┼───────┘   ┌──────────────┤
                     ↑        [ 地面道路系统 ]
                   中轴
```

### 建筑类型与数量

| 建筑 | 数量 | 位置 | 描述 |
|------|------|------|------|
| 🏛️ **主殿** | 1座 | 中轴最前 | 最大建筑，歇山顶屋顶，带斗拱与门楼 |
| 🏛️ **配殿** | 2座（左右） | 两侧中后 | 中等规模，庑殿顶屋顶 |
| 🚪 **山门** | 1座 | 中轴最前 | 门楼建筑，带檐角与门柱 |
| 🗼 **宝塔** | 1座 | 左后 | 多层塔结构，带檐角 |
| 🔔 **钟楼** | 1座 | 右后 | 多层塔结构，带檐角 |

### 场景特点

- **中轴对称布局**：主殿、山门位于中轴线上，配殿与宝塔/钟楼左右对称
- **体素化风格**：所有内容物使用 `BoxGeometry` 构建，呈现方块立体感
- **中式建筑元素**：飞檐翘角、斗拱结构、红墙青瓦、木色柱梁
- **道路系统**：连接各建筑，中轴与侧路清晰
- **装饰元素**：灯笼、石狮、树木、地面铺装
- **光照系统**：多光源模拟晨昏氛围，有明确阴影

## 🚀 运行方式

### 1. 环境准备

- **Node.js** ≥ 18.x
- **npm** ≥ 9.x

### 2. 安装与启动

```bash
# 克隆项目（或复制项目文件）
cd voxel-chinese-architecture

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 打开浏览器访问 http://localhost:5173
```

### 交互操作

| 操作 | 说明 |
|------|------|
| 🖱️ **左键拖拽** | 绕场景旋转视角 |
| 🔘 **滚轮** | 缩放（拉近/拉远） |
| 🖱️ **右键拖拽** | 平移视角 |

## 💡 技术说明

- **Three.js v0.162.0**：通过 CDN 加载，无需 npm
- **Vite**：开发构建工具（可选）
- **原生 JavaScript**：无框架依赖，即开即用
- **体素构建**：所有模型使用 `BoxGeometry` 组合，适合体素风格
- **性能优化**：合理控制几何复杂度，确保 ≥ 30fps
